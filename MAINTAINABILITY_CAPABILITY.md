# Maintainability capability

Maintainability `0.1.0` is TDE's first derived capability. It consumes normalized Code Size and Complexity evidence only and invokes no native analyzer. It derives a bounded repository maintainability index from canonical code-line and average cyclomatic-complexity measurements.

Missing dependency evidence blocks the capability. Status is VALIDATED; custom weights, file/symbol views, policy thresholds, and broader dependencies are future work.
