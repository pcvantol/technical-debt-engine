# Comparison schema

Comparison supports current versus baseline, branch baseline, previous release, and repository-to-repository only when metric semantics prove compatibility. It records IDs of both evidence records, schema compatibility, metric deltas, finding transitions, regressions, improvements, limitations, and status.

Cross-language or cross-tool comparison is `UNSUPPORTED` when semantic compatibility cannot be proven. See [`schemas/comparison.schema.json`](schemas/comparison.schema.json).
