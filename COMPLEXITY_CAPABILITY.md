# Complexity capability

Complexity `0.1.0` is the analyzer-rich reference capability. Python is implemented through `complexity.radon` with Radon `6.0.1`; C/C++ (Lizard), C# (Roslyn), JavaScript/TypeScript (ESLint), and Swift tooling are reserved adapter selections, not implemented claims.

The adapter emits canonical cyclomatic repository average, median, and maximum metrics plus high-complexity findings. Analyzer identity and raw-output hash are retained in evidence. Status is **VALIDATED** on the current Python/macOS environment; multi-language and cross-platform qualification remain pending.
