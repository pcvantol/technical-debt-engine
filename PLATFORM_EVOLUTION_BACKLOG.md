# Platform Evolution Backlog

This document preserves the former platform-evolution option set as historical
planning context. It is not an active Generation 2 backlog.

Active work is exclusively the consumer-driven `1.0.0` backlog in
[PRODUCT_BACKLOG.md](PRODUCT_BACKLOG.md). Platform expansion, cloud evidence
storage, remote APIs, dashboards, broad distribution targets, parallel or
distributed execution, and IDE work are post-1.0 options unless a documented
DJConnect pilot need activates one under [ROADMAP_GOVERNANCE.md](ROADMAP_GOVERNANCE.md).
